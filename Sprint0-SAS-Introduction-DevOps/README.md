## Vue d'ensemble du sprint

Ce sprint constitue le **Sas d'Adaptation Simplon (SAS)** - une introduction progressive et structurée au monde DevOps. Il prépare les apprenants aux défis techniques et méthodologiques du programme en établissant les bases conceptuelles, pratiques et environnementales essentielles, incluant l'installation complète de l'environnement de développement.

## Objectifs pédagogiques

- Découvrir l'organisme de formation, le programme DevOps et la terminologie
- Installer et configurer l'environnement de développement DevOps complet
- Maîtriser les outils fondamentaux et workflows de collaboration
- Comprendre l'importance de la communication dans les équipes DevOps

## Objectifs techniques

Installation environnement, VirtualBox, Vagrant, Docker Desktop, Python, concepts DevOps, outils collaboratifs, workflows Git, communication équipe, documentation technique, culture DevOps

## Structure du sprint

### 5 séances de découverte et installation

Le Sprint 0 comprend 5 séances thématiques conçues pour une immersion progressive et une préparation technique complète :

1. **Séance 1** : Introduction organisme, programme et culture DevOps
2. **Séance 2** : Installation environnement de développement
3. **Séance 3** : Panorama des outils DevOps
4. **Séance 4** : Introduction tests et qualité
5. **Séance 5** : Infrastructure et déploiements

Chaque séance suit la méthodologie Framework HASSAN avec 4 LABs progressifs et un quiz de validation.

### Séance 2 : Installation Environnement de Développement

**Concepts abordés** : Environnement de développement, virtualisation, containerisation, outils DevOps

- Architecture de l'environnement de développement DevOps
- Installation et configuration de VirtualBox
- Configuration de Vagrant pour l'automatisation des VMs
- Installation de Docker Desktop et premiers containers
- Configuration de Python et environnements virtuels
- Installation des outils essentiels : Git, VS Code, Chocolatey
- Configuration SSH et authentification
- Validation et tests de l'environnement complet

**LABs pratiques** :

- LAB 1 : Installation et configuration VirtualBox + Vagrant
- LAB 2 : Configuration Docker Desktop et premiers containers
- LAB 3 : Configuration Python et environnement de développement
- LAB 4 : Environnement DevOps complet avec automation (Challenge)

### Séance 3 : Panorama des Outils DevOps

**Concepts abordés** : Écosystème d'outils, chaîne DevOps, intégration et automation

- Cartographie complète de la chaîne d'outils DevOps
- Critères de sélection et évaluation des outils
- Intégration et orchestration de l'écosystème
- Stratégies d'adoption et migration d'outils
- Architecture de référence et bonnes pratiques
- Tendances et évolutions de l'écosystème DevOps

**LABs pratiques** :

- LAB 1 : Audit et évaluation de l'écosystème d'outils existant
- LAB 2 : Conception architecture d'outils DevOps cible
- LAB 3 : Comparatif et sélection d'outils CI/CD
- LAB 4 : Pipeline multi-outils intégré (Challenge)

### Séance 4 : Introduction Tests et Qualité

**Concepts abordés** : Tests automatisés, qualité du code, métriques de qualité, stratégies de test DevOps

- Fondamentaux des tests dans l'écosystème DevOps
- Types de tests : unitaires, intégration, fonctionnels, performance
- Stratégies de tests automatisés et shift-left testing
- Outils de tests et frameworks de qualité
- Métriques de qualité et couverture de code
- Integration des tests dans les pipelines CI/CD
- Culture qualité et responsibility partagée
- Tests d'infrastructure et tests de sécurité

**LABs pratiques** :

- LAB 1 : Configuration d'environnement de tests et premiers tests unitaires
- LAB 2 : Implémentation de tests d'intégration et analyse de qualité
- LAB 3 : Métriques de qualité et reporting automatisé
- LAB 4 : Pipeline de tests automatisés complet (Challenge)

### Séance 5 : Infrastructure et Déploiements

**Concepts abordés** : Infrastructure as Code, déploiements automatisés, environnements, monitoring

- Principes de l'Infrastructure as Code (IaC)
- Stratégies de déploiement : blue-green, canary, rolling
- Gestion des environnements et promotion du code
- Automatisation des déploiements et rollbacks
- Monitoring et observabilité des déploiements
- Configuration management et secrets management
- Architecture cloud et déploiements distribués
- Patterns de déploiement et best practices

**LABs pratiques** :

- LAB 1 : Configuration IaC avec Terraform/Ansible basics
- LAB 2 : Déploiements automatisés et stratégies de release
- LAB 3 : Monitoring et observabilité des déploiements
- LAB 4 : Pipeline de déploiement complet multi-environnements (Challenge)

## Structure des séances

Chaque séance suit la structure Framework HASSAN :

**Organisation** :

- **Cours théorique** : 45 minutes de concepts et démonstrations
- **LABs pratiques** : 4 exercices progressifs (75 minutes total)
- **Quiz validation** : 15 questions avec seuil 72% (15 minutes)

**Progression pédagogique** :

- LAB 1 (15 min, 5 points) : Diagnostic des dysfonctionnements organisationnels
- LAB 2 (20 min, 5 points) : Application des principes CALMS et Psychological Safety
- LAB 3 (20 min, 5 points) : Analyse des métriques DORA et performance DevOps
- LAB 4 (20 min, 5 points) : Construction de business case et calcul ROI DevOps

## Évaluation et validation

**Système de points par séance** :

- 4 LABs : 30 points (5+5+5+15)
- 1 Quiz : 15 points (15 questions)
- Total : 45 points par séance

**Validation sprint** :

- Score minimum : 32/45 points par séance (72%)
- Complétion : 5 séances validées
- Total sprint : 225 points (162 points minimum)

**Critères qualité** :

- Environnement de développement fonctionnel et configuré
- Maîtrise des concepts DevOps fondamentaux
- Capacité d'utilisation des outils collaboratifs
- Compréhension des enjeux organisationnels
