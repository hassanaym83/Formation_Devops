# Brief Projet - Consolidation Linux et Bash Scripting

## Description

Ce brief projet permet de **consolider et appliquer** les compétences acquises lors de :

- **Semaine 1 Sprint 1** : Fondamentaux Linux (système, processus, réseau, services)
- **Séance 1 Semaine 2** : Fondamentaux Bash pour DevOps
- **Séance 2 Semaine 2** : Bash Scripting Intermédiaire

## Objectif

Développer **SysMonitor Pro** : un outil d'administration système complet combinant expertise Linux et scripting Bash avancé.

## Contenu du dossier

- **Brief_Projet_Consolidation_Linux_Bash.md** : Cahier des charges complet du projet
- **Structure attendue** : Architecture modulaire avec configuration externalisée
- **Livrables** : Code source, documentation, tests et démonstration

## Compétences évaluées

### Linux Administration

- Monitoring système (CPU, mémoire, disque)
- Gestion des processus et services
- Surveillance réseau et connectivité
- Utilisation native des outils Linux

### Bash Scripting

- Architecture modulaire avec fonctions
- Gestion d'erreurs robuste (set -e, trap)
- Validation des entrées et paramètres
- Système de logging structuré

### DevOps

- Automation de la maintenance
- Génération de rapports HTML
- Configuration externalisée
- Monitoring proactif

## Durée recommandée

**7 jours** avec phases progressives :

1. **Architecture** (2 jours)
2. **Développement** (3 jours)
3. **Intégration** (2 jours)

## Évaluation

- **Critères techniques** : 70 points (architecture, fonctionnalités, scripts)
- **Critères qualité** : 20 points (robustesse, documentation)
- **Critères innovation** : 10 points (fonctionnalités avancées)
