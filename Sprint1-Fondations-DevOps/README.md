## Objectifs Pédagogiques

Transition développeur vers DevOps avec les outils de base nécessaires pour automatiser, déployer et gérer des infrastructures modernes. Approche "Infrastructure-First" pour une compréhension solide des fondamentaux système avant le développement.

## Contenu Technique

### Semaine 1 - Système & Automation (10h)

**Objectif** : Maîtriser les fondamentaux Linux et l'automation système

- **Séance 1** : Linux Fondamentaux - CLI, système de fichiers, permissions
- **Séance 2** : Gestion Processus et Services - Processus, systemd, monitoring
- **Séance 3** : Réseaux et Sécurité - Configuration réseau, pare-feu, SSH
- **Séance 4** : Services Avancés et Automatisation - Apache/Nginx, MySQL/PostgreSQL, cron
- **Séance 5** : Bash Scripting et Automation Avancée - Déploiement Blue-Green, monitoring intelligent

### Semaine 2 - Python DevOps (10h)

**Objectif** : Maîtriser Python pour l'automation DevOps

- **Séance 1** : Fondamentaux Python - Variables, types, structures de contrôle
- **Séance 2** : Fonctions et Modules - Organisation et réutilisation du code
- **Séance 3** : Gestion d'erreurs et fichiers - Robustesse et persistance
- **Séance 4** : Python avancé DevOps - POO, décorateurs, tests automatisés
- **Séance 5** : Automation et APIs - Intégration et orchestration de services

### Semaine 3 - Version Control (10h)

**Objectif** : Maîtriser Git et GitLab pour la collaboration

- **Séance 1** : Git Workflows - Branches, merge, rebase, stratégies
- **Séance 2** : Collaboration avancée - Code review, résolution conflits
- **Séance 3** : GitLab Integration - Issues, MR, wiki, CI/CD basique
- **Séance 4** : Git pour Infrastructure - IaC versioning, hooks
- **Séance 5** : Projet collaboratif - Application pratique complète

## Progression Pédagogique

### 📚 **Approche "Infrastructure-First"**

Cette progression suit la logique DevOps moderne :

```
Sprint 0 (Setup) → Semaine 1 (Infrastructure) → Semaine 2 (Code) → Semaine 3 (Collaboration)
      ↓                    ↓                      ↓                    ↓
Environnement → Système Linux & Automation → Python DevOps → Git & GitLab
```

### 🎯 **Justification Pédagogique**

1. **Continuité post-Sprint 0** : Transition naturelle de l'environnement vers l'infrastructure
2. **Infrastructure avant Code** : Comprendre le système avant d'automatiser
3. **Fondamentaux solides** : Base Linux robuste pour le développement Python
4. **Progression logique** : Système → Automation → Collaboration

## Technologies Maîtrisées

**Langages** : Bash, Python  
**Systèmes** : Linux (Ubuntu/CentOS), systemd, réseau  
**Automation** : Scripts Bash avancés, Python automation  
**Outils** : Git, GitLab, monitoring système  
**Méthodologies** : Workflows Git, collaboration DevOps

## Contraintes Pédagogiques

- **Durée par séance** : 2 heures exactement
- **Répartition** : 45 min théorie / 75 min pratique
- **Évaluation** : 4 LABs + 1 Quiz (15 questions) par séance
- **Objectif** : Contenu limité au scope de la séance uniquement
- **Support** : Auto-suffisant pour absence apprenant

## Livrables Finaux

1. **Infrastructure Linux** configurée et sécurisée avec automation
2. **Scripts Bash avancés** pour déploiement et monitoring
3. **Scripts Python** d'automation DevOps fonctionnels
4. **Repository Git** avec workflows et documentation
5. **Projet intégré** combinant toutes les technologies
