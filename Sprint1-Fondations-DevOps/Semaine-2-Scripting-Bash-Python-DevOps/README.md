## Objectif de la Semaine

Maîtriser les deux langages de scripting essentiels DevOps : Bash pour l'automation système et Python pour l'intégration et l'orchestration. Cette semaine combine la puissance du shell Unix avec la flexibilité de Python.

## Programme Détaillé

### Séance 1 - Fondamentaux Bash DevOps (2h)

**Objectif** : Apprendre les bases du scripting Bash pour les apprenants débutants

- **Théorie (45min)** : Introduction Bash, variables, paramètres, conditions, boucles, opérations de base
- **Pratique (75min)** : 4 LABs progressifs + Quiz 15 questions
- **Livrables** : Scripts Bash fonctionnels pour tâches système de base

### Séance 2 - Bash Scripting Intermédiaire (2h)

**Objectif** : Progresser vers des concepts Bash intermédiaires avec fonctions et modularité

- **Théorie (45min)** : Gestion d'erreurs, fonctions structurées, scripts modulaires, automatisation maintenance
- **Pratique (75min)** : 4 LABs progressifs + Quiz 15 questions
- **Livrables** : Scripts modulaires avec fonctions réutilisables et gestion d'erreurs

### Séance 3 - Fondamentaux Python (2h)

**Objectif** : Installer Python et maîtriser la syntaxe de base et les structures de données

- **Théorie (45min)** : Installation Python, configuration environnement, variables, types, opérateurs, structures conditionnelles
- **Pratique (75min)** : 4 LABs progressifs + Quiz 15 questions
- **Livrables** : Environnement Python configuré + Scripts Python de manipulation de données

### Séance 4 - Fonctions et Modules (2h)

**Objectif** : Organiser et réutiliser le code avec les fonctions et modules + **Type Hints et Decorators**

- **Théorie (45min)** : Définition de fonctions, paramètres, modules et packages + Type hints basiques + Decorators simples
- **Pratique (75min)** : 4 LABs progressifs + Quiz 15 questions
- **Livrables** : Bibliothèque de fonctions utilitaires DevOps avec type hints

### Séance 5 - Gestion d'erreurs et fichiers (2h)

**Objectif** : Développer des scripts robustes avec gestion d'erreurs et I/O + **Context Managers et Logging JSON**

- **Théorie (45min)** : Try/except, logging, manipulation de fichiers + Context managers + Logging JSON structuré
- **Pratique (75min)** : 4 LABs progressifs + Quiz 15 questions
- **Livrables** : Scripts de traitement de logs et configuration avec logging JSON

### Séance 6 - Python Intermédiaire DevOps (2h)

**Objectif** : Utiliser les concepts intermédiaires pour des solutions DevOps + **Tests avec pytest**

- **Théorie (45min)** : POO, décorateurs, tests unitaires, virtualenv + pytest basique
- **Pratique (75min)** : 4 LABs progressifs + Quiz 15 questions
- **Livrables** : Framework de test et classes métier avec tests automatisés

### Séance 7 - Automation et APIs (2h)

**Objectif** : Automatiser et intégrer des services via APIs

- **Théorie (45min)** : Requests, JSON, automation système, scheduling
- **Pratique (75min)** : 4 LABs progressifs + Quiz 15 questions
- **Livrables** : Scripts d'automation et client API

## Compétences Développées

### Compétences Techniques

- **Bash Avancé** : Fonctions, gestion d'erreurs, automation système
- **Syntaxe Python** : Variables, types, structures de contrôle
- **Fonctions et Modules** : Organisation et réutilisation du code
- **Gestion d'erreurs** : Robustesse et debugging
- **POO Python** : Classes, méthodes, héritage
- **APIs et Automation** : Intégration et orchestration

### Compétences DevOps

- **Scripting système** : Automation Bash pour infrastructure
- **Scripting d'automation** : Tâches répétitives automatisées
- **Traitement de logs** : Analyse et monitoring
- **Intégration de services** : APIs REST et webhooks
- **Tests automatisés** : Qualité et fiabilité du code
- **Gestion de configuration** : Fichiers de config et secrets

## Outils et Technologies

- **Bash Shell** : Automation système et scripts DevOps
- **Python 3.9+** : Langage principal pour intégration
- **pip** : Gestionnaire de packages Python
- **venv** : Environnements virtuels Python
- **requests** : Client HTTP Python
- **json** : Manipulation de données structurées
- **logging** : Gestion des logs système
- **unittest** : Tests automatisés Python

## Évaluation

- **28 LABs** : 4 par séance (débutant à expert)
- **7 Quiz** : 15 questions chacun (seuil 72%)
- **Projet fil rouge** : Suite d'outils Bash + CLI Python évolutif
- **Participation** : Contribution active et entraide

## Prérequis

- **Bases algorithmiques** : Variables, boucles, conditions
- **Logique de programmation** : Résolution de problèmes
- **Accès administrateur** : Pour installation Python et packages
- **Anglais technique** : Documentation Python
- **Ordinateur avec** : Windows 10+, Linux, ou macOS

**Note** : La Séance 1 couvre l'installation complète de Python, aucune installation préalable requise.
