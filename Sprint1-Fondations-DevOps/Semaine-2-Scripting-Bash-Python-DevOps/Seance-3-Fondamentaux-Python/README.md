# Simplon Maghreb - Sprint 1 - Semaine 2 - Séance 1 : Fondamentaux Python pour DevOps

## Description de la séance

Cette première séance introduit l'installation et la configuration de Python, puis les concepts fondamentaux dans un contexte DevOps. Elle couvre l'environnement de développement, les variables, types de données, opérateurs, structures conditionnelles et boucles essentiels pour l'automation d'infrastructure.

## Objectifs pédagogiques

- **Installer et configurer** Python sur différents systèmes d'exploitation
- **Configurer l'environnement** de développement DevOps
- Manipuler variables et types Python pour scripts DevOps
- Appliquer opérateurs et structures conditionnelles
- Utiliser boucles pour automation de tâches répétitives
- Créer scripts monitoring et alertes

## Objectifs techniques

Installation Python, pip, environnements virtuels, IDE/éditeurs, variables, int, float, str, bool, list, dict, if/elif/else, for, while, opérateurs, f-strings, monitoring DevOps
