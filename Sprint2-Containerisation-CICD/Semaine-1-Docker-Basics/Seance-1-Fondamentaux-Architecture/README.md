# Simplon Maghreb - Formation DevOps

# Sprint 2 - Semaine 1 - Séance 1 : Fondamentaux et Architecture Docker

## Objectifs pédagogiques

- Comprendre les concepts fondamentaux de la containerisation et ses avantages
- Maîtriser l'architecture Docker et ses composants essentiels
- Installer et configurer Docker Engine selon les bonnes pratiques
- Manipuler les conteneurs avec les commandes Docker essentielles

## Objectifs techniques

Docker Engine, images vs conteneurs, registry Docker Hub, Dockerfile basics, commandes CLI, lifecycle des conteneurs, architecture client-serveur

## Vue d'ensemble des LABs

Cette séance comprend 3 LABs pratiques :

📝 **LAB 1** - Installation et premiers pas Docker (8 points, 20 minutes)  
📝 **LAB 2** - Manipulation de conteneurs et images (10 points, 25 minutes)  
📝 **LAB 3** - Application multi-conteneurs avec communication (12 points, 35 minutes)

**Durée totale** : 80 minutes  
**Points totaux** : 30 points  
**Seuil de validation** : 22/30 points (72%)

## Contenu de la séance

### 1. Cours magistral et démonstrations

- Concepts fondamentaux de la containerisation
- Architecture Docker et composants
- Installation et configuration
- Commandes essentielles et bonnes pratiques

### 2. Travaux pratiques

- 3 LABs progressifs avec énoncés détaillés
- Validation par étapes avec corrections automatisées
- Cas d'usage réels DevOps

### 3. Évaluation

- Quiz de validation post-séance (15 minutes)
- 20 questions couvrant tous les concepts abordés
